# Images & Logos Directory

In Next.js, all static images, logos, and graphic assets placed in `public/` are directly accessible from the browser root path.

### Folders structure:
- `/public/images/logos/` -> Place cafe logos, favicons, branding graphics here.
  - Usage in code: `<img src="/images/logos/logo.png" alt="Celebration Food Cafe Logo" />`
- `/public/images/menu/` -> Place photos of dishes and menu items here.
  - Usage in code: `<img src="/images/menu/masala-chai.jpg" alt="Masala Chai" />`
